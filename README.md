## 30초 홍보영상 무료 초안

`video/output/promo_30s_free.mp4`: 학과 홈페이지 사진과 모션그래픽으로 만든 30초 세로 영상 (AI 미사용, 무음). 다시 만들기: `python video/build_free.py`

## 이번 주에 할 일 (Quick Start)

- [ ] 인스타 이름 칸을 `창원대 회계학과 | 국립창원대학교`로 바꾸고 소개글·링크 5개 정리
- [ ] 인스타 프로페셔널 계정 전환 → 현재 팔로워·도달 수치를 KPI 문서에 기록
- [ ] 유튜브 채널 설명·배너·재생목록 정리, 학과 소개 영상을 채널 트레일러로 지정
- [ ] 홈페이지 퀵메뉴에 인스타·유튜브 아이콘 추가
- [ ] 유튜브 채널명을 `국립창원대학교 회계학과`로 바꾸고 기존 영상 6개 제목 수정 (분석 문서 2장)
- [ ] 카드뉴스 `05_합격취업실적` 업로드 (캡션은 원고 21번)
- [ ] 서포터즈 모집 공고 게시

## 사용 전 꼭 확인할 것

- 문서의 `[ ]` 표시는 학과 실제 정보(인원, 연락처, 합격자 등)로 채워야 하는 자리입니다. **확인되지 않은 수치는 넣지 마세요.**
- 시험 정보(CPA·세무사)는 2026년 기준 일반적인 구조입니다. 게시 전 금융감독원·Q-Net 최신 공고와 대조하세요.
- 수능·정시 원서접수 날짜는 캘린더에 확정되어 있지 않습니다. 입학처 공식 일정을 확인해 해당 주차 게시물을 조정하세요.
- 홈페이지·유튜브는 2026.9.27 직접 분석한 내용을 반영했습니다. 인스타그램은 로그인이 필요해 분석하지 못했으니, 인사이트 화면을 캡처해 주시면 추가로 반영하겠습니다.
