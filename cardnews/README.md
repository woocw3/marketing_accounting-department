## 문구 수정 · 새 카드뉴스 만들기

1. `slides.mjs`의 문구를 고치거나 새 세트를 추가합니다. (슬라이드 종류: 표지·목록·체크리스트·오해vs진실·시험표·마무리)
2. 색상은 `build.mjs` 상단의 `C` 값만 바꾸면 전체에 적용됩니다. (대학 공식 UI 색상 적용 권장)
3. 아래 명령으로 이미지를 다시 만듭니다.

```bash
cd cardnews
npm install
npx playwright install chromium   # 최초 1회
npm run build
```

- 한글 폰트 **Noto Sans KR**(Google Fonts 무료)이 컴퓨터에 설치되어 있어야 합니다.
- 캔바(Canva) 등 디자인 툴을 쓰신다면 이 이미지를 레이아웃 참고용으로 활용해도 됩니다.
