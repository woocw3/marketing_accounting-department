# 유튜브 운영 가이드

채널: `@CWNUdepartmentofaccounting`

## 1. 유튜브의 역할

인스타그램이 "지나가다 발견"하는 채널이라면, 유튜브는 **"궁금해서 검색"**하는 채널입니다.
고등학생·학부모는 학과를 고를 때 유튜브에서 `회계학과 뭐 배워요`, `회계학과 전망`, `공인회계사 되는 법`, `창원대 회계학과`를 검색합니다.
**이 검색어에 답하는 영상이 하나씩 쌓일수록 광고비 없이 몇 년간 꾸준히 유입됩니다.**

## 4. 검색 최적화(SEO) 공식

### 제목
```
[검색어가 들어간 질문/약속] | 창원대 회계학과
```
- ✓ `회계학과 오면 진짜 뭐 배워요? 교수님께 직접 물었습니다 | 창원대 회계학과`
- ✓ `공인회계사 되는 법, 시험 구조부터 공부 기간까지 | 합격 선배 인터뷰`
- ✓ `세무직 공무원 합격한 회계학과 선배의 하루 | 선배는 지금`
- ✗ `2026학년도 회계학과 학술제` (아무도 검색하지 않음)

### 설명란 템플릿
```

국립창원대학교 회계학과 교수님이 직접 답해 드립니다.

⏱ 목차
00:00 인트로
00:30 회계학과 1학년 때 배우는 것
02:10 공인회계사·세무사 준비
04:00 졸업 후 진로

🏫 국립창원대학교 회계학과 홈페이지 https://www.changwon.ac.kr/acc/main.do
📷 인스타그램 https://www.instagram.com/cwnu_department_of_accounting
📝 입시 문의: [입학처 링크]
```

- **목차(타임스탬프)**를 넣으면 구글 검색 결과에 "주요 순간"으로 노출됩니다.
- 해시태그는 3개 (제목 위에 표시됨)

### 태그·자막
- 태그: 창원대 회계학과, 국립창원대학교, 회계학과, 회계학과 전망, 회계학과 진로, 공인회계사, 세무사
- **한국어 자막(SRT) 업로드**: 자동 자막보다 검색 정확도가 올라가고 무음 시청자도 붙잡습니다.

## 5. 썸네일 원칙

`cardnews/output/youtube_thumbnails/`의 예시를 템플릿으로 사용하세요.

1. **글자는 10자 내외 두 줄**, 휴대폰 화면에서 읽힐 크기
2. **사람 얼굴 + 표정** (교수님·선배 실물 사진을 오른쪽에 배치하면 클릭률 상승)
3. 학과 색상(남색 + 노랑) 통일 → 채널 목록에서 한눈에 "우리 학과 영상"으로 인식
4. 제목과 썸네일 문구는 **다르게** (썸네일=감정·호기심, 제목=검색어)

## 6. 업로드 주기

| 형식 | 주기 | 비고 |
|---|---|---|
| 쇼츠 | 주 2회 | 인스타 릴스 재활용 |
| 롱폼(5~12분) | 월 2회 | 인터뷰·학과 소개·브이로그 |
| 커뮤니티 게시물 | 주 1회 | 투표("가장 궁금한 진로는?"), 다음 영상 예고 |

## 7. 쇼츠 → 롱폼으로 구독자 전환

- 쇼츠 업로드 시 **"관련 동영상"**에 같은 주제의 롱폼 영상을 연결
- 롱폼 끝 20초에 **최종 화면**: 구독 버튼 + 다음 추천 영상
- 롱폼 안에서 "고정 댓글"로 질문 유도 → 답변 영상 제작

## 8. 기존 영상 정리 (1회성 작업)

1. 기존 영상 6개의 **제목을 검색형으로 수정** (재업로드 불필요). 바꿀 제목은 `00_채널현황_분석.md` 2장 표에 있습니다.
2. 특강 영상 4개는 `🎓 현직자 특강` 재생목록으로 묶고, 각 영상에서 60초 하이라이트를 잘라 쇼츠로 올리기
3. `우청원 학과장님 인사말`(조회수 280)을 **채널 트레일러**로 지정하고, 설명란에 학과 소개·목차·링크 추가
4. 웹에서 검색되는 `[학과소개] 국립창원대학교 회계학과` 영상은 이 채널에 없으므로, 대학 채널 영상이면 재생목록에 추가
5. 오타 수정: `2025년 세미자 자료` → `세미나`
