# 인스타그램 운영 가이드

계정: `@cwnu_department_of_accounting`

## 1. 프로필 최적화 (오늘 바로 할 일)

인스타그램 검색은 **사용자 이름(@핸들)**과 **이름(Name) 칸**만 검색 대상입니다. 핸들이 영문으로 길기 때문에 이름 칸에 한글 검색어를 꼭 넣어야 합니다.

| 항목 | 권장안 |
|---|---|
| 이름(Name) | `창원대 회계학과 | 국립창원대학교` |
| 카테고리 | 교육 / 대학교 |
| 소개(Bio) | 아래 예시 |
| 링크 | 최대 5개: ① 학과 홈페이지 ② 유튜브 채널 ③ 입학처 모집요강 ④ 입시 상담(구글폼/오픈채팅) ⑤ 최신 영상 |
| 프로필 사진 | 대학 로고 + "회계학과" 문구가 들어간 원형 이미지 (작게 보여도 읽히도록 글자 크게) |

**소개글 예시 (택1)**
```
📊 국립창원대학교 회계학과 공식 계정
🎓 1979년 개설 | 공인회계사·세무사·세무직 공무원의 시작
💬 입시·전공 궁금한 점은 DM으로 편하게!
👇 학과 홈페이지 · 유튜브 · 입시 상담
```
```
숫자로 세상을 읽는 사람들 📈
국립창원대 회계학과 | CPA·세무사·공무원·금융
매주 [1분 회계 상식] 업로드
👇 예비 신입생 필독 링크
```

**하이라이트(스토리 고정) 구성**
`학과소개` · `입시Q&A` · `진로·합격` · `선배는지금` · `학과생활` · `서포터즈`
(하이라이트 커버는 학과 색상(남색+노랑)으로 통일)

## 2. 콘텐츠 포맷별 운영 원칙

| 포맷 | 비중 | 목적 | 원칙 |
|---|---|---|---|
| **릴스** | 50% | 비팔로워 도달, 팔로워 증가 | 첫 1초에 질문·자막 훅, 7~30초, 자막 필수(무음 시청 대비), 트렌드 음원은 인스타 제공 음원만 |
| **카드뉴스(캐러셀)** | 30% | 저장·공유 유도, 전문성 | 표지 1장에서 궁금증 유발 → 정보 → 마지막 장 행동 유도(팔로우·저장·댓글), 5~8장 |
| **사진 게시물** | 20% | 학과 소식, 행사 기록 | 행사 사진도 "캡션에 외부인이 얻을 정보" 한 줄 추가 |
| **스토리** | 주 3회 이상 | 기존 팔로워와 관계 유지 | 질문 스티커, 투표, 퀴즈로 참여 유도 → 답변을 릴스로 재가공 |

> 알고리즘 참고: 인스타그램은 **공유(DM 보내기)**와 **저장**, **끝까지 본 비율**을 중요한 신호로 봅니다.
> 좋아요보다 "친구에게 보내고 싶은" 콘텐츠를 목표로 하세요.

## 3. 릴스 제작 공식

```
[0~1초]  훅: 화면 자막 + 말로 질문 던지기   "회계학과 오면 수학 잘해야 해요?"
[1~20초] 답: 핵심 3가지 이내, 컷 전환 2~3초 간격
[마지막]  행동 유도: "더 궁금하면 댓글" / "팔로우하고 2편 보기"
```
- 세로 9:16, 1080×1920, 자막은 화면 중앙~하단 1/3 (하단 UI에 가리지 않게)
- 사람 얼굴이 첫 장면에 나오면 도달률이 좋아집니다
- 같은 영상을 유튜브 쇼츠에도 업로드 (워터마크 없는 원본으로)

## 4. 해시태그 세트

해시태그는 **3~5개**만 정확하게 씁니다. (많이 쓴다고 도달이 늘지 않습니다)

| 용도 | 해시태그 |
|---|---|
| 기본(항상) | `#창원대 #창원대학교 #국립창원대학교 #창원대회계학과` |
| 입시 | `#고3 #수시 #정시 #학과추천 #진로고민` |
| 전문직 | `#공인회계사 #세무사 #CPA #회계사되는법` |
| 공무원 | `#세무직공무원 #관세직 #공무원준비` |
| 생활 정보 | `#연말정산 #종합소득세 #재테크 #사회초년생` |
| 학과 생활 | `#대학생일상 #새내기 #과잠 #시험기간` |

## 5. 업로드 시간

- 고등학생 타깃: **평일 저녁 7~10시**, **일요일 저녁** (야간 자율학습·학원 이후)
- 학부모 타깃: 평일 점심 12~1시, 저녁 8~10시
- 운영 3주 후 `인사이트 → 팔로워 활동 시간`을 보고 조정

## 6. 공동 게시(Collab) 활용법

게시물 작성 → `사람 태그하기` → `공동 작업자 초대` → 상대 계정이 수락하면 **양쪽 피드에 동시 노출**됩니다.

| 협업 상대 | 콘텐츠 아이디어 |
|---|---|
| 대학 공식 계정·입학처 | 학과 소개 릴스, 입시 Q&A |
| 경영대학·타 학과 | "경영학과 vs 회계학과 차이점" 콜라보 |
| 학생회·동아리 | 축제 부스, 스터디 모집 |
| 동문 회계법인·세무법인 | "선배는 지금" 인터뷰 |
| 고교 진로동아리 | 전공 체험 행사 후기 |

## 8. 팔로워를 늘리는 이벤트 (선택)

무작위 경품 이벤트는 경품만 노리는 팔로워가 늘어나 이후 도달률을 떨어뜨립니다. 대신 **타깃이 참여할 이유가 있는 이벤트**를 권장합니다.

- **"수험생 응원 댓글 이벤트"** (수능 전): 응원 댓글 남긴 수험생 중 추첨으로 학과 굿즈
- **"회계 퀴즈 챌린지"**: 스토리 퀴즈 연속 정답자에게 기프티콘
- **"새내기 환영 인증"** (합격 발표 후): 합격 인증 + 학과 계정 태그 → 신입생 오리엔테이션에서 굿즈 전달

> 경품 이벤트는 인스타그램 프로모션 가이드라인(인스타그램이 후원하지 않는다는 문구 명시)과 대학 내부 규정을 확인하세요.
