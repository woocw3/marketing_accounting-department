## 1. 연결 상태와 도구 구성 (2026.9.27 확인)

| 역할 | 도구 | 상태 | 비고 |
|---|---|---|---|
| 영상 클립 생성 | 힉스필드 MCP `generate_video` | ✅ 연결됨 | Plus 플랜, **잔여 25크레딧** |
| 내레이션 (일레븐랩스) | 힉스필드 MCP `generate_audio` → `text2speech_v2` 모델, `variant: "elevenlabs"` | ✅ 사용 가능 | 별도 일레븐랩스 MCP는 **연결되어 있지 않음**. 힉스필드 안의 일레븐랩스 엔진을 사용 |
| 학과장 목소리 복제 (선택) | 힉스필드 MCP `create_voice` | ✅ 사용 가능 | 10초~3분 녹음 필요, 복제 시 크레딧 차감 |
| 한글 자막·타이틀·편집 | 이 저장소의 `cardnews` 렌더러 + ffmpeg (무료) 또는 힉스필드 Higgsedit(`video-editing` 워크플로) | ✅ | **한글 글자는 AI 영상 모델로 만들지 않고 편집 단계에서 넣음** |
| 배경음악 | 유튜브 오디오 보관함 무료 음원 | — | 힉스필드 음악 모델은 게임 전용이라 사용 불가 |
| 가로(16:9) 버전 | 힉스필드 `reframe` | ✅ | 홈페이지·유튜브 본편용 |

> 일레븐랩스 계정을 따로 쓰고 싶으시면 claude.ai 설정 → 커넥터에서 일레븐랩스를 연결하면 됩니다. 이 경우 한국어 전용 보이스 라이브러리를 고를 수 있어서 선택지가 넓어집니다. 지금 구성(힉스필드 안의 일레븐랩스)만으로도 제작은 가능합니다.

### 모델 선택
| 용도 | 모델 | 이유 |
|---|---|---|
| 실제 사진 → 움직이는 영상 | **Kling v3.0** (`kling3_0`, `mode: std`, `sound: off`, 9:16, 5초) | 시작 이미지 지원, 소리를 끄면 크레딧 절약 |
| 사진 없는 추상 장면 (숫자·그래프) | **Seedance 2.5** (`seedance_2_5`, `t2v`, 720p, `generate_audio: false`) | 텍스트만으로 생성, 4~30초 조절 가능 |
| 내레이션 | `text2speech_v2` + `variant: elevenlabs` | 요청하신 일레븐랩스 엔진 |

## 4. AI 영상 프롬프트 초안

모든 프롬프트 끝에 **"no text, no letters, no logos"**를 붙입니다. AI 영상 모델은 한글을 깨뜨려서 그리기 때문에 글자는 편집에서 넣습니다.

| # | 모델 | 프롬프트 (영문) |
|---|---|---|
| 1 | Seedance 2.5, 4초 | Macro shot of calculator digits dissolving into glowing particles that rise and form a night city skyline with rising financial chart lines, deep navy and warm yellow color palette, cinematic, smooth camera pull-back, no text, no letters, no logos |
| 2 | Kling 3.0, 시작 이미지=경영대학 건물 사진 | Slow cinematic dolly-in toward the university building, soft morning sunlight, gentle cloud movement, trees swaying lightly, keep the building architecture unchanged, no text, no letters |
| 3 | Kling 3.0, 시작 이미지=강의·세미나 사진 | Subtle parallax camera drift across the classroom scene, natural light, students remain still and natural, no facial changes, no text, no letters |
| 4 | Seedance 2.5, 5초 | Over-the-shoulder view of hands typing on a laptop showing abstract data dashboards with bar charts and flowing numbers, modern study room, navy and teal tones, shallow depth of field, no readable text, no faces, no logos |
| 6 | Kling 3.0, 시작 이미지=캠퍼스 전경 사진 | Slow aerial-style push-in over the campus at golden hour, warm light, calm and hopeful mood, keep buildings unchanged, no text, no letters |

> 3번 컷처럼 학생이 나오는 사진은 **얼굴이 바뀌지 않도록** 움직임을 최소화합니다. 실제 재학생이 아닌 AI 인물을 재학생처럼 보이게 만들지 않습니다.

## 5. 제작 순서

| 단계 | 할 일 | 도구 | 크레딧 |
|---|---|---|---|
| 0 | 학과장님이 원본 사진 3장(경영대학 건물, 강의·세미나, 캠퍼스 전경)과 원고 승인 | — | 0 |
| 1 | 사진 업로드 | 힉스필드 `media_upload` → `media_confirm` | 0 |
| 2 | **테스트 1컷**: 2번 컷(건물)만 먼저 생성해 품질과 실제 차감 크레딧 확인 | `generate_video` (Kling 3.0) | 확인 필요 |
| 3 | 목소리 결정: A안이면 `create_voice`로 복제, B안이면 첫 문장으로 목소리 2~3개 비교 | `create_voice` / `generate_audio` | 확인 필요 |
| 4 | 나머지 AI 컷 4개 한 번에 생성 | `generate_video_batch` → `jobs_wait` | 확인 필요 |
| 5 | 전체 내레이션 생성 (27초) | `generate_audio` (`text2speech_v2`, `variant: elevenlabs`) | 확인 필요 |
| 6 | 편집: 컷 연결, 한글 자막·타이틀(카드뉴스와 같은 남색·노랑 디자인), 5번 컷 모션그래픽, 배경음악, 엔드카드 | 저장소 렌더러 + ffmpeg (또는 Higgsedit) | 0 |
| 7 | 9:16 원본 → 16:9 가로 버전 | `reframe` | 확인 필요 |
| 8 | 학과장님 최종 검수 → 게시 | — | 0 |

**크레딧 관련**: 현재 잔액은 25크레딧입니다. 모델별 정확한 차감량은 도구에서 미리 알려 주지 않아서, **2단계 테스트 1컷으로 실제 차감량을 확인한 뒤** 나머지 진행 여부를 결정합니다. 영상 4~5컷과 내레이션을 모두 만들기에는 부족할 가능성이 높으니, 필요하면 크레딧을 충전하거나 AI 컷을 줄이는 방법(예: 2·3·6번은 실제 사진에 편집 줌 효과만 적용)을 고릅니다.
