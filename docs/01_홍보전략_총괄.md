# 국립창원대학교 회계학과 온라인 홍보 전략 (총괄)

> 목표: **홈페이지·유튜브·인스타그램에 외부인 유입을 늘리고 팔로워(구독자)를 늘린다.**
> 기간: 1차 12주 집중 운영(2026년 10월~12월, 수시 합격자 발표·수능·정시 원서접수 시즌) → 이후 연간 운영으로 전환

---

## 1. 현재 상황 진단

| 채널 | 역할 | 흔히 겪는 문제 | 개선 방향 |
|---|---|---|---|
| 홈페이지 (`changwon.ac.kr/acc`) | 공식 정보, 신뢰, 입학 전환 | 대학 공통 CMS라 디자인 자유도가 낮음. 공지 위주라 외부인이 볼 게 적음. SNS로 가는 링크가 눈에 띄지 않음 | 예비 신입생용 페이지, SNS 배너, 검색에 걸리는 게시물 제목 |
| 유튜브 (`@CWNUdepartmentofaccounting`) | 깊이 있는 정보, 검색 유입 | 행사 기록 영상 위주면 외부인이 검색으로 찾아오지 않음. 업로드 간격이 불규칙함 | "검색되는 질문"에 답하는 영상, 쇼츠 정기 업로드 |
| 인스타그램 (`@cwnu_department_of_accounting`) | 발견, 친근함, 소통 | 행사 사진 앨범형 게시물은 재학생만 반응함. 계정명이 길어 검색이 어려움 | 저장·공유되는 정보형 카드뉴스, 릴스, 공동 게시(Collab) |

> 참고: 학과 SNS 계정은 **"재학생 소식지"**로 운영되는 경우가 많습니다. 외부인이 팔로우하는 이유는 **"나에게 쓸모 있는 정보"**가 있어서입니다.
> 따라서 콘텐츠의 무게중심을 **학과 소식 → 외부인이 궁금해하는 정보**로 옮기는 것이 이 전략의 핵심입니다.

## 2. 타깃 고객

| 우선순위 | 타깃 | 이들이 궁금해하는 것 | 주력 채널 |
|---|---|---|---|
| ★★★ | **고등학생(고1~고3)·N수생** | 회계학과가 뭘 배우는지, 나랑 맞는지, 졸업 후 진로, 합격선·전형 | 인스타 릴스, 유튜브 쇼츠 |
| ★★★ | **학부모·고교 진로교사** | 취업·전문직 실적, 국립대의 장점(등록금·장학금), 학과 신뢰도 | 유튜브 롱폼, 홈페이지, 네이버 검색 |
| ★★ | **회계·세무에 관심 있는 일반인·타 학과생** | 연말정산·종합소득세·재테크 상식, CPA·세무사 시험 정보 | 인스타 카드뉴스, 유튜브 쇼츠 |
| ★★ | **재학생·신입생** | 학과 행사, 스터디, 장학, 선배 이야기 | 인스타 스토리, 홈페이지 공지 |
| ★ | **동문·지역 기업·회계법인** | 학과 근황, 멘토링·채용 협력 | 인스타, 유튜브 인터뷰 |

**핵심 메시지 (모든 콘텐츠에 반복)**
1. **"경남에서 회계 전문가가 되는 가장 확실한 길"** — 1979년 개설된 전통, 국립대
2. **"전공 수업이 곧 전문직 시험 과목"** — 공인회계사·세무사·세무직 공무원
3. **"선배가 증명한다"** — 합격자·동문 인터뷰 (실제 사례로만)

## 3. 채널별 역할과 유입 흐름

```
 [발견]                    [관심]                   [신뢰]                    [행동]
 인스타 릴스       ─┐     인스타 카드뉴스   ─┐     유튜브 롱폼 인터뷰  ─┐    팔로우·구독
 유튜브 쇼츠        ├──▶  유튜브 정보 영상   ├──▶  홈페이지 학과 소개    ├──▶ 입시 상담 문의
 네이버·구글 검색  ─┘     공동 게시(Collab) ─┘     합격·취업 실적       ─┘    원서 지원
```

- **인스타그램 = 발견과 소통의 입구.** 릴스와 카드뉴스로 처음 보는 사람을 끌어온다.
- **유튜브 = 신뢰와 검색의 창고.** "회계학과 뭐 배워요", "공인회계사 되는 법" 같은 검색어로 꾸준히 유입된다. 쇼츠는 인스타 릴스를 그대로 재활용한다.
- **홈페이지 = 최종 전환 지점.** 모든 SNS 게시물의 링크는 홈페이지(또는 입학처)로 연결하고, 홈페이지에는 SNS로 가는 버튼을 크게 둔다.

## 4. 7대 실행 전략

### ① 원 소스 멀티 유즈 (OSMU): 한 번 찍고 세 번 쓴다
세로 영상(9:16) 1개 → 인스타 릴스 + 유튜브 쇼츠 + 홈페이지 게시판 삽입. 제작 부담을 1/3로 줄이는 것이 지속 운영의 핵심입니다.

### ② 고정 시리즈로 "다음 편"을 기다리게 만든다
| 시리즈명 | 형식 | 주기 | 내용 |
|---|---|---|---|
| **1분 회계 상식** | 릴스/쇼츠 | 주 1회 | 교수님·재학생이 60초 안에 설명하는 생활 회계·세금 상식 |
| **회계학과 팩트체크** | 카드뉴스 | 격주 | 회계학과·전문직에 대한 오해와 진실 |
| **선배는 지금** | 롱폼 + 카드뉴스 | 월 1회 | CPA·세무사·공무원·기업 재무팀 동문 인터뷰 |
| **회계학과 브이로그** | 릴스/롱폼 | 월 1회 | 재학생의 하루, 시험기간, 학과 행사 |
| **입시 Q&A** | 스토리 → 릴스 | 입시 시즌 주 1회 | 스토리 질문 스티커로 모은 질문에 답변 |

### ③ 공동 게시(Collab)와 계정 간 협업
인스타 공동 게시 기능을 쓰면 **양쪽 계정 팔로워 모두에게** 노출됩니다.
- 대학 본부 공식 계정, 입학처 계정, 경영대학 계정
- 총학생회·단과대 학생회·학과 학생회·동아리(회계 스터디 등)
- 동문 회계법인·세무법인(동문 인터뷰 공동 게시)
- 인근 고등학교 진로 동아리(전공 체험 행사 후 공동 게시)

### ④ 재학생 홍보단 "회계학과 서포터즈" 운영
학과장·조교만으로는 주 3회 이상 운영이 불가능합니다. 재학생 4~6명으로 서포터즈를 꾸려 촬영·편집·출연을 맡기고, 봉사시간·활동 인증서·소정의 활동비·우수 콘텐츠 시상으로 보상합니다. 서포터즈 본인의 지인 네트워크 공유만으로도 초기 도달이 크게 늘어납니다. (상세: `07_운영체계_서포터즈.md`)

### ⑤ 교수진의 "얼굴"을 활용한다
교수님이 직접 등장하는 1분 영상은 학부모·교사에게 강한 신뢰를 줍니다. 대본은 서포터즈가 준비하고 교수님은 촬영만 5~10분 참여하는 구조로 부담을 줄입니다.

### ⑥ 검색에 걸리는 제목을 쓴다
외부인은 학과 이름이 아니라 **질문**으로 검색합니다.
- ✗ "2026 회계학과 학술제 개최" → ✓ "회계학과 학술제에서는 뭘 할까? | 창원대 회계학과"
- ✗ "동문 특강" → ✓ "지방 국립대에서 공인회계사 된 선배의 공부법 | 창원대 회계학과"
- 모든 제목·설명에 **"창원대 회계학과"**, **"국립창원대학교 회계학과"**를 꼭 넣습니다.

### ⑦ 오프라인에서 온라인으로 연결
입시박람회, 고교 방문 설명회, 전공 체험, 학과 행사 현수막, 강의실 게시판에 **인스타·유튜브 QR코드**를 넣습니다. "팔로우하면 입시 Q&A 자료 PDF 제공"처럼 팔로우할 이유를 함께 줍니다.
