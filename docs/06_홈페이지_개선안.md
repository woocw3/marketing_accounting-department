# 홈페이지 개선안

주소: https://www.changwon.ac.kr/acc/main.do

학과 홈페이지는 대학 공통 CMS(콘텐츠 관리 시스템) 위에 있어 디자인을 크게 바꾸기 어렵습니다.
그래서 이 개선안은 **학과 관리자 권한으로 바로 할 수 있는 것**과 **대학 정보전산원·입학처에 요청할 것**으로 나눴습니다.

---

## 1. 학과에서 바로 할 수 있는 것

### ① 메인 배너(비주얼) 문구 교체
외부인이 첫 화면에서 3초 안에 "여기가 어떤 곳인지" 알 수 있어야 합니다.

| 안 | 메인 문구 | 보조 문구 | 버튼 |
|---|---|---|---|
| A | 숫자로 세상을 읽는 사람들 | 1979년부터 경남의 회계 전문가를 키워 온 국립창원대학교 회계학과 | 예비 신입생 안내 / 유튜브 보기 |
| B | 공인회계사·세무사의 시작, 여기서부터 | 전공 수업이 곧 전문직 시험 과목입니다 | 학과 소개 영상 / 인스타그램 |
| C | 회계학과, 나랑 맞을까? | 1분 적성 체크하고 선배들의 진로를 확인하세요 | 적성 체크 / 진로 지도 |

> 배너 이미지는 `cardnews/` 도구로 제작 가능 (슬라이드 크기만 배너 규격으로 변경)

### ② SNS 연결을 눈에 띄게
- 메인 화면 **퀵메뉴**에 `유튜브`, `인스타그램` 아이콘 추가
- 메인에 **최신 유튜브 영상 1개 임베드** (학과 소개 영상 고정)
- 모든 공지 게시물 하단 고정 문구:
  ```
  📷 인스타그램 @cwnu_department_of_accounting | 🎥 유튜브 국립창원대학교 회계학과
  학과 소식을 가장 빠르게 받아 보세요.
  ```

### ④ 자주 묻는 질문(FAQ) 초안

| 질문 | 답변 초안 |
|---|---|
| 수학을 잘 못해도 괜찮나요? | 회계에 필요한 수학은 대부분 사칙연산 수준이며, 계산은 엑셀과 계산기를 활용합니다. 꼼꼼함과 논리적 사고가 더 중요합니다. |
| 문과·이과 중 어느 쪽이 유리한가요? | 계열과 무관합니다. 1학년 회계원리부터 기초를 차근차근 배웁니다. |
| 공인회계사·세무사 준비를 지원하나요? | 전공 교육과정이 시험 과목과 직결되어 있고, 스타벅스 CPA 고시반을 운영하며, 매 학기 세무사·세무공무원 특강을 엽니다. 전문자격시험 1차에 합격하면 졸업논문을 대체할 수 있습니다. |
| 어떤 자격증을 딸 수 있나요? | 전산회계·전산세무, ERP정보관리사 등 실용 자격증을 수업(전산회계, 전산세무회계, ERP 과목)과 연계해 준비합니다. 전산세무 1급, TESAT 1등급, 매경TEST 700점 이상은 졸업논문을 대체합니다. |
| 졸업 후 진로는요? | 공인회계사·세무사 등 전문직, 세무·관세직 공무원, 공기업, 금융기관, 일반기업 재무·회계 부서 등으로 진출합니다. |
| 복수전공·부전공이 가능한가요? | [학칙에 따른 내용 기재] |
| 장학금 제도가 있나요? | 교내·국가장학금 외에 학과 장학금이 있으며, 직전 학기 성적·토익 점수·학과 행사 참여도를 반영해 선발합니다. 자세한 내용은 `학과활동안내 > 장학금 안내`를 참고하세요. |
| 학과 분위기는 어떤가요? | 인스타그램과 유튜브 브이로그에서 재학생의 일상을 확인하실 수 있습니다. |
| 대학원 진학도 가능한가요? | 일반대학원·경영대학원 회계 관련 과정으로 진학할 수 있습니다. [링크] |
| 입시 상담은 어디서 하나요? | 모집요강은 입학처, 전공·학과 생활 질문은 학과 사무실 또는 인스타그램 DM으로 문의해 주세요. |

### ⑥ 게시물 제목을 "검색되는 제목"으로
네이버·구글은 게시물 제목을 가장 중요하게 봅니다.
- ✗ `[공지] 특강 안내` → ✓ `[창원대 회계학과] 공인회계사 합격 선배 특강 안내`
- ✗ `합격을 축하합니다` → ✓ `창원대 회계학과, 제○○회 공인회계사 시험 ○명 최종 합격`
- 게시물 본문 첫 문장에 `국립창원대학교 회계학과`를 한 번 넣기
- 사진에는 파일명과 대체텍스트(alt)를 `창원대-회계학과-학술제-2026.jpg`처럼 입력

## 2. 대학 본부에 요청할 것

| 요청 대상 | 요청 내용 | 기대 효과 |

| 홍보실 | 대학 공식 SNS에 학과 콘텐츠 공동 게시·공유 | 대학 계정 팔로워에게 노출 |

## 3. 홈페이지 밖의 "검색 창구"도 챙기기

고등학생·학부모는 학과 홈페이지보다 **네이버 검색**과 **대학 정보 커뮤니티**를 먼저 봅니다.

- **네이버 검색**: "창원대 회계학과"를 직접 검색해 보고 첫 페이지에 무엇이 나오는지 매달 확인
- **네이버 블로그(선택)**: 여력이 되면 카드뉴스를 블로그 글로 재가공해 올리면 네이버 검색 노출이 크게 늘어납니다. (카드뉴스 이미지 + 캡션만으로 글 1편 완성)
- **대학 정보 커뮤니티**: 대학백과(univ100) 등의 학과 Q&A에 학과 공식 답변을 남기면 정확한 정보 제공과 유입 효과를 함께 얻습니다.
- **대학어디가**: 학과 정보(교육과정·진로)가 최신인지 입학처와 확인
