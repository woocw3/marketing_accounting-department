# 유튜브 영상 기획안

- 쇼츠 12편: 인스타 릴스와 **같은 영상**을 올립니다 (9:16, 60초 이내).
- 롱폼 6편: 월 2편씩 3개월 분량입니다.
- 촬영 장비: 스마트폰 + 핀마이크(무선 마이크) + 삼각대면 충분합니다. **음질이 화질보다 중요합니다.**

### 쇼츠 대본 예시 (S1)

```
[0:00] (재학생 정면, 자막 크게) "수포자인데 회계학과 가도 돼요?"
[0:02] "결론부터 말하면, 네! 가능합니다."
[0:05] (자막: 회계학과에서 쓰는 수학) "대부분 더하기, 빼기, 곱하기, 나누기예요."
[0:09] (엑셀 화면 인서트) "복잡한 계산은 엑셀이랑 계산기가 해 줘요."
[0:13] (자막: 진짜 필요한 것) "대신 꼼꼼함, 그리고 왜 이렇게 되는지 따지는 논리력이 중요해요."
[0:19] "저도 고등학교 때 수학 [ ]등급이었는데 지금 잘 다니고 있어요."
[0:23] (자막: 궁금한 거 댓글로!) "회계학과 궁금한 거 댓글로 남겨 주세요!"
```

## Part 2. 롱폼 기획안 6편

### L1. 회계학과 오면 진짜 뭐 배워요? 교수님께 직접 물었습니다
- **목표 검색어**: 회계학과 뭐 배워요, 회계학과 커리큘럼, 창원대 회계학과
- **길이**: 7~9분 / **출연**: 교수님 1~2명 + 진행 재학생 1명
- **구성**
  1. (0:00) 인트로: 재학생이 "회계학과 오기 전 가장 궁금했던 것"
  2. (0:40) 1학년: 경영학원론, 경제학원론, 회계원리
  3. (2:00) 2학년: 중급재무회계, 원가회계, 세법개론, **AI와회계데이터분석(2026 개편)**
  4. (3:30) 3~4학년: 고급재무회계, 세무회계, 회계감사, 재무제표분석, ERP, 방학 현장실습
  5. (5:00) 자격증·시험: 졸업논문 대체 자격(전산세무 1급, 전문자격 1차 합격 등), 스타벅스 CPA 고시반
  6. (6:30) 교수님이 말하는 "이런 학생이 오면 좋겠다"
  7. (8:00) 마무리: 구독·댓글 질문 유도
- **출연 추천**: 과목별 담당 교수님이 한 부분씩 (재무회계 안미강·이건, 세법 김형국, 원가·관리회계·ERP 송신근)
- **썸네일**: `thumb_01_교수님께물었다.png`

### L2. [선배는 지금] 공인회계사 합격 선배의 공부 루틴
- **목표 검색어**: 공인회계사 공부법, CPA 합격 수기, 지방대 CPA
- **길이**: 10~12분 / **출연**: 최근 합격 동문
- **질문 목록**
  1. CPA를 결심한 계기는?
  2. 1차·2차 준비 기간과 하루 공부 시간표
  3. 학과 수업·스터디가 도움 된 점
  4. 가장 힘들었던 순간과 극복법
  5. 지금 하는 일(수습 회계사의 하루)
  6. 고등학생·후배에게 한마디
- **썸네일**: `thumb_02_합격선배.png`

### L3. [선배는 지금] 지역인재 7급·세무직 공무원이 된 회계학과 선배
- **목표 검색어**: 지역인재 7급, 세무직 공무원 하는 일, 세무직 공무원 회계학과
- **근거**: 홈페이지의 `2024 지역인재 7급 합격 수기`(조회수 3,042), `9급 지방직 세무공무원 합격 수기`(2,128)가 가장 많이 읽힌 글 → 같은 선배를 영상으로 인터뷰
- **구성**: 세무서의 하루 → 회계학과 전공이 시험·업무에 도움 되는 점 → 공무원 준비 팁

### L4. 회계학과 재학생 솔직 토크 (장단점, 학점, 동아리)
- **목표 검색어**: 회계학과 장단점, 회계학과 현실, 회계학과 후회
- **출연**: 1·2·4학년 재학생 각 1명
- **포인트**: 단점도 솔직하게 말할수록 신뢰가 올라갑니다. 대본 없이 질문 카드만 준비

### L5. 국립창원대 회계학과 캠퍼스·학과 투어 브이로그
- **목표 검색어**: 창원대 캠퍼스 투어, 창원대 회계학과
- **구성**: 정문 → 학과 건물 → 강의실 → 학과 사무실 → 스터디 공간 → 학생식당 → 캠퍼스 명소
- **팁**: 입시 시즌(9월·12월) 전에 공개

### L6. 공인회계사 vs 세무사, 무엇을 준비할까? (교수님 해설)
- **목표 검색어**: 회계사 세무사 차이, 회계사 세무사 연봉, 회계사 세무사 난이도
- **구성**: 하는 일 → 시험 구조 → 준비 기간 → 진로 다양성 → 회계학과에서 준비하는 방법
- **주의**: 연봉·합격률 등 수치는 금융감독원·Q-Net 공식 통계만 인용하고 출처를 화면에 표기
